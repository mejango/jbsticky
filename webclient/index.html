Dip one in, get a sticky one out

  1. Exchange any token for a sticky version back.
  2. Stick more anytime, unstick anytime too.
  3. Sticky tokens can be airdropped reward tokens by anyone, claimable weekly.
  4. Sticky tokens can have a bonus: all who unstick give back a little to all who stick.
  5. Sticky token rules are set when the token is made, and can't be changed.

Worth it

  1. The ledger remembers who has stuck around — stickiness we can attest to.
  2. Airdrops from anyone, and bonuses paid by unsticking, go to those who stick around.
  3. Unstick anytime to take your share, minus any stickiness bonus tax you leave behind.
  4. No admins, no updates, no surprises. The code is public and can't be changed.
  5. Works for any token — across Ethereum, Arbitrum, Base, and Optimism.

Juicy insides

Under the hood, every sticky token is a fine-tuned Juicebox — inheriting Juicebox's security, and making it completely interoperable with other Juicebox-based systems.

    Read about fees

    Sticking is always free. With a stickiness bonus on, each unstick pays a 2.5% fee to the Juicebox project — the same fee any Juicebox project pays on funds leaving. The unsticker gets $JBP6 tokens back for it, making them a part-owner of Juicebox itself, earning a cut of everyone else's fees. Sticky tokens with no bonus unstick fee-free.
